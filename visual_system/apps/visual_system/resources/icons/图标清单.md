## 在 Qt 中使用

### 加载 SVG 图标

```cpp
// 方式一：直接用 QIcon 加载 SVG（Qt 支持 SVG 渲染）
QIcon icon(":/icons/工具栏/单次采集.svg");
btn->setIcon(icon);
btn->setIconSize(QSize(18, 18));

// 方式二：通过 QPixmap 加载
QPixmap pm(":/icons/状态指示/正常.svg");
label->setPixmap(pm.scaled(16, 16, Qt::KeepAspectRatio, Qt::SmoothTransformation));
```

### 在 .qrc 资源文件中注册

```xml
<RCC>
  <qresource prefix="/icons">
    <file>resources/icons/标题栏/切换主题.svg</file>
    <file>resources/icons/标题栏/最小化.svg</file>
    <!-- ... 按需添加 -->
  </qresource>
</RCC>
```

### 在 CMakeLists.txt 中启用 Qt SVG 模块

```cmake
find_package(Qt5 COMPONENTS Svg REQUIRED)
target_link_libraries(${PROJECT_NAME} PRIVATE Qt5::Svg)
```

## 主题适配说明

Lucide SVG 默认使用 `currentColor` 作为描边色，这意味着图标颜色会跟随 CSS `color` 属性自动适配主题。在 Qt 中：

- **亮色主题**下图标显示为深色描边
- **暗色主题**下通过 QSS 设置 `color` 属性即可让图标变为浅色
- 也可以通过修改 SVG 中的 `stroke` 属性来自定义颜色
