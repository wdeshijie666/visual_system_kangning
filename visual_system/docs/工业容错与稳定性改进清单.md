# 视觉抓取系统 — 工业容错与稳定性改进清单

> 面向工业制造产线的架构审视结论与落地项。  
> 状态：本轮已按 P0 → P1 → P2 顺序落地核心项。

## 总评

当前工程具备可联调的 MVP 能力：启动防呆、算法进程崩溃拉起、周期失败写 NG、设备状态灯、单实例与崩溃转储。  
本轮重点补齐运行时容错：触发与周期解耦、SHM 超时复位、采图失败短路、设备巡检重连、报警与熔断、日志轮转等。

## 落地原则

1. 优先保证周期不堵死、状态机可恢复、失败语义正确。  
2. 抽离可复用的独立模块，降低与业务的耦合。  
3. 避免过度设计；命名通俗；注释说明意图与边界。
