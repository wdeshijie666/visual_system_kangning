# SmartGuide 视觉系统使用手册

适用：现场正式生产（真 PLC、真相机）  
说明：文中「【截图位】」请自行插入对应软件截图后，整篇可粘贴到飞书。

---

## 1. 使用前请先知道

本软件负责：拍照 → 算出结果 → 交给产线 PLC。常用工位是 **R05**、**R09**。平时由产线 PLC 自动叫软件干活。

请记住这几条：

1. 双击运行的是程序文件夹里的 `SmartGuide.exe`（下文叫「程序目录」）。
2. 改配置文件后，一般要 **关掉软件再打开** 才生效。
3. 点了 **启动**，软件才跟着产线干活；点了 **停止**，产线再叫它也不理会。
4. **手动触发、历史回放** 只给调试用，正式生产请不要用（见最后一节）。

程序目录里常用这些东西：

| 你看到的 | 干什么用 |
|----------|----------|
| `SmartGuide.exe` | 打开软件 |
| `config` 文件夹 | 系统和相机名单 |
| `camera_parmas` 文件夹 | 各相机配方（按序列号命名） |
| `alg_program` 文件夹 | 算法程序和算法参数 |
| `data` 文件夹 | 跑产时保存的数据 |
| `logs` 文件夹 | 日志，出问题可给技术员看 |

## 2. 日常怎么操作

### 2.1 界面大概长什么样

从上到下、从左到右大致是：

- 上面：菜单、以及 **启动 / 停止** 按钮  
- 左边：设备是否正常、工位忙不忙、运行日志  
- 中间：R05 / R09 的画面，下面是检测结果表  
- 右边：相机相关，可导入配方  
- 最底下：一句话提示  

> **【截图位 S-01｜主界面】**  
> 拍整窗。标出：启动/停止、左边设备区、中间画面和结果表、右边相机区。  
> （此处粘贴截图）

### 2.2 开机并开始生产

1. 确认程序目录里有 `config`、`alg_program` 等文件夹。  
2. 双击 `SmartGuide.exe`，等启动画面结束。  
3. 看左边设备信息：算法正常、要用的相机显示已连接；PLC 能连上。  
4. 点工具栏 **启动**。  
5. 之后由产线自动触发即可。界面上会出现新画面和新结果。

补充：

- 有一台相机暂时连不上，往往 **仍能启动**：坏的那一侧会按不合格回给产线，好的一侧照常。  
- 若点不了启动，把鼠标放在按钮上，或看底下提示/左边状态，按提示处理或叫技术员。

> **【截图位 S-02｜设备都正常】**  
> 拍左边「设备信息」：PLC、算法、两台相机尽量都是正常状态。  
> （此处粘贴截图）

> **【截图位 S-03｜启动和停止】**  
> 拍工具栏「启动」「停止」按钮。  
> （此处粘贴截图）

### 2.3 暂停生产

点 **停止**。  
停止之后，产线再触发，软件也不会再跑——这是正常现象，不是死机。要继续生产，再点一次 **启动**。

> **【截图位 S-04｜已停止】**  
> 拍点停止后的界面或底栏提示。  
> （此处粘贴截图）

### 2.4 生产时看什么

| 看哪里 | 正常时 | 不对劲时 |
|--------|--------|----------|
| 左边 PLC | 已连接；启动后状态正常 | 未连接 → 查网线、找技术员看配置 |
| 左边算法 | 显示在跑 | 不正常 → 等一会或重启软件；仍不行找技术员 |
| 工位文字 | 空闲 → 工作中 → 完成 | 一直卡在工作中 → 记一下日志，找技术员 |
| 中间画面 | 触发后会换图 | 一直没图 → 看相机是否已连接 |
| 结果表 | 每个工位最多 5 条结果 | 老是全不合格 → 看日志，找技术员 |
| 日志 | 没有一堆红字报错 | 把报错内容留给技术员 |

结果里常见：

- **1**：合格  
- **2**：不合格

> 拍：有新画面、结果表有数、工位不是一直卡死。  
> （此处粘贴截图）

> **【截图位 S-06｜结果表】**  
> 拍结果表特写，能看清合格/不合格和数值。  
> （此处粘贴截图）

### 2.5 给相机换配方

某台相机要换拍摄参数时：

1. 相机先显示 **已连接**。  
2. 在右边选好 **目标相机（序列号）**。  
3. 点 **导入配方文件**，选对应的 `.json`。  
4. 也可从菜单 **设备 → 2D相机参数导入** 做同样的事。

注意：

- 一次只改你选中的那一台。  
- 建议把确认好的配方文件，按「序列号.json」放进 `camera_parmas` 文件夹，下次开机也会自动用。

> **【截图位 S-07｜右边导入配方】**  
> 拍：目标相机下拉框 +「导入配方文件」按钮。  
> （此处粘贴截图）

> **【截图位 S-08｜导入窗口】**  
> 拍菜单「2D相机参数导入」弹出的窗口。  
> （此处粘贴截图）

### 2.6 退出软件

菜单 **文件 → 退出**，或点窗口关闭。  
若正在生产，会弹出确认；确认后会先停产再退出。

> **【截图位 S-09｜退出确认】**  
> 拍退出时的确认框。

## 3. 现场常改的配置（白话）

改的都是 **程序目录里的文件**。改完请 **重启软件**。  
没把握时不要乱改，交给技术员。下面只写正式生产常要核对的项。

### 3.1 总配置：`config/setting.json`

用记事本等工具打开（注意逗号、引号别删坏）。

| 你要关心的 | 正式生产一般怎么写 | 人话说明 |
|------------|--------------------|----------|
| `runMode` | `production` | 正式生产必须写成这个 |
| `plc` 里的 `gateway` | 现场 PLC 的 IP | 写错就连不上产线 |
| `plc` 里的 `path` | 多为 `1,0` | 以现场电气给的为准 |
| `plc` 里两个标签名 | 一般保持出厂名 | 必须和 PLC 程序里的名字一致 |
| `plc` 里的 `simAutoTrigger` | `false` | 正式生产请关着 |
| `stations` 里 r05 / r09 的 `enabled` | 要用就 `true` | 暂时不用某工位可改成 `false` |
| 是否保存深度图等 | 建议开着深度保存 | 方便以后查问题、回放 |

IP、标签名若不清楚，问现场电气或调试人员，不要自己猜。

### 3.2 相机名单：`config/devices.json`

这里登记每台相机：

| 项 | 人话说明 |
|----|----------|
| 序列号 `serial` | **一定要写成相机机身上的真实序列号** |
| 工位 `station` | `r05` 或 `r09` |
| 编号 `id` | 和总配置里工位绑的相机编号一致即可 |

### 3.3 相机配方文件夹：`camera_parmas`

- 文件名：`序列号.json`（和相机序列号对得上）。  
- 软件连上相机后会自动去读。  
- 没有这个文件也能开机，但参数可能不是你想要的。

### 3.4 算法参数：`alg_program/algo_config.json`

正式生产请核对：

| 你要关心的 | 正式生产一般怎么写 | 人话说明 |
|------------|--------------------|----------|
| 通路仿真是否打开 | 关掉（`enabled` 为 `false`） | 打开就不是按真实算法算 |
| 每个工位自己的参数文件名 | 指向 `alg_program` 里真实存在的文件 | R05、R09 可以各用一份不同的 |
| 是否用工位真实算法 | 一般保持打开 | 按调试人员给定为准 |
| 共用参考点文件 | 顶层 `referencePointConfig`，默认 `reference_point.json` | 两工位共用一份；缺文件也能算，但会打警告并用库默认点 |

两工位工艺不一样时：准备两份参数文件，在配置里分别写上不同文件名。参考点仍共用一份，除非技术员另行说明。

## 4. 开班前快速核对

**开软件前**

- [ ] 程序是现场正式用的那一套  
- [ ] PLC 的 IP、相机序列号已按现场改好  
- [ ] 正式生产模式（不是仿真）  
- [ ] 算法文件夹和参数文件都在  
- [ ] 自动仿真触发类开关是关的  

**开起来并点了启动后**

- [ ] 左边设备看起来正常  
- [ ] 产线侧能确认软件在线/有心跳  
- [ ] 触发一轮后：有图、有结果

## 5. 常见情况怎么办

| 现象 | 你可以先做 | 再不行 |
|------|------------|--------|
| 点不了启动 | 看提示；等算法起来；查网线 | 找技术员 |
| 停了之后产线叫不动 | 再点一次 **启动** | — |
| 显示 PLC 不正常 | 确认已点启动；查网 | 核对 IP 等配置 |
| 有触发但没图 | 看相机是否已连接 | 查序列号、线、配方 |
| 结果老是不合格 | 看日志有没有报错 | 找技术员看参数 |
| 只坏一个工位 | 看这个工位相机和结果 | 找技术员 |
| 改了参数像没改 | **重启软件** 再试 | 找技术员 |

## 6. 附录：调试用功能（正式生产请勿用）

### 6.1 手动跑一轮

先点 **停止**，再点 **手动触发 R05 / R09**。  
会当场拍照、算结果，并送给 PLC。生产过程中不要用。

> **【截图位 D-01｜手动触发】**  
> 拍停止后、手动触发按钮可点的状态。  
> （此处粘贴截图）

### 6.2 用以前的数据再算一遍

1. 先 **停止**。  
2. 菜单 **离线测试 → 历史数据回放 R05 / R09**。  
3. 选以前保存在 `data` 里的某次文件夹（里面要有深度图一类文件）。  
4. 不会重新拍照，一般也不改写产线 PLC。

> **【截图位 D-02｜历史回放】**  
> 拍菜单入口，以及选文件夹的窗口。  
> （此处粘贴截图）

### 6.3 调试相关配置（仅供技术员）

正式生产请保持关闭或不要改乱。主要包括：

- 把运行模式改成仿真  
- 自动每隔几秒假触发（只在仿真程序里有用；正式真机程序里无效）  
- 各种「调试保存」「强制用某张图」「通路仿真出固定结果」一类开关  

拿不准时：**全部保持现场交付时的设置，只改 IP、序列号、配方和算法参数文件名。**
