# VisualSystem 架构说明

工业视觉主控软件，运行于 `visual_system/` 工程。产线主控为 AB PLC（CameraPC_Interface V0.2），3D 相机为 RVC SDK，算法侧通过共享内存 IPC（MVP 可用 Mock 进程）。

## 1. 产线流程

```
PLC 心跳 (CameraToPLC_Int[0].0, 2s 0/1)
    ↓
PLCToCamera_Int[0].1 触发 R05/R07  或  [0].2 触发 R09
    ↓
VisualSystem: 采集 → 算法 → 写 5 条 Log → WriteSequenceCompleted
    ↓
UI 刷新工位结果表
```

- **工位**：物理 R05、R09；逻辑机械臂 R05、R07（共用 `[0].1` 触发）、R09（`[0].2`）。
- **5 工件**：一次视觉周期向对应工位 `CameraToPLC_Int` 结果区写入 **5 组 Log**（Status / X / Y / R / Diameter / Length）。
- **PLC 清零**：除心跳外 `CameraToPLC_Int` 由 PLC 清零；视觉侧只写，不重复清结果区。

## 2. 逻辑分层

| 层 | 目录 | 职责 |
|----|------|------|
| UI | `apps/visual_system/` | Qt 深色三栏 MainWindow、工位结果表、设备状态、离线测试 |
| App | `libs/app_core/` | AppContext、EventBus、SequenceEngine |
| Domain | `libs/device_abstraction/` | IPlcClient、ICamera3D、IAlgoService、IMesReporter |
| Adapters | `libs/adapter_*` | AB PLC、RVC 相机、SHM/Mock 算法 |

```
MainWindow → SequenceEngine → IPlc / ICamera / IAlgo
                ↓
            EventBus → UI 刷新
```

## 3. 核心模块

### SequenceEngine

独立工作线程轮询 PLC（20ms），边沿检测触发后执行：

`Capture → Algo → WriteLogResults → WriteSequenceCompleted → NotifyCycleCompleted`

- R05 工位周期默认同时写 R05 + R07 结果区（与 V0.2 双机械臂映射一致）。
- 离线模式：`RunOfflineCycle(StationId)` 跳过 PLC 触发，仍走采集/算法/写 PLC 路径。
- 采图落盘：`{程序目录}/{dataPath}/{yyyyMMdd}/`，文件名前缀 `yyyyMMdd_hhmmss`：
  - `{prefix}_{R05|R09}_{camera_id}_depth.pgm|.tif`
  - `{prefix}_{R05|R09}_{camera_id}_pointcloud.ply`
  - `{prefix}_{R05|R09}_algo_result.txt`（单行 CSV，5×6 字段，无表头）
- 数据保留：`DataStubRetentionCleaner` 后台线程启动后立即扫描，此后每小时轮询；按文件名前缀时间戳（秒级）删除超过 **7 天** 的存根，并移除空日期子目录。

### VisionPlcAdapter

封装 `AB_PLC` 的 `vision_plc_driver`：Connect、StartHeartbeat(2000)、PollTrigger、WriteLogResults、WriteSequenceCompleted。无 libplctag 时自动使用 MemoryTransport 便于本地仿真。

### RvcCameraAdapter

- SDK 根目录：`D:/Program Files/RVBUST/RVC/RVCSDK`
- 导入库：`${RVC_ROOT}/lib/RVC.lib`
- 运行时：`${RVC_ROOT}/runtime/RVC.dll`（构建后拷贝至 exe 目录）
- CMake 变量：`RVC_ROOT`、`RVC_LIB_DIR`、`RVC_RUNTIME_DIR`；未找到 lib 时使用 Stub 相机
- 配方：`LoadRecipeFile` → RVC `LoadSettingFromFile`

### ShmAlgoService / MockAlgoService

- 默认进程内 `MockAlgoService` 返回 5 条 OK Log。
- `setting.json` 设 `"useShm": true` 时改用 Win32 命名共享内存，需先启动 `tools/mock_algo_service`。

### UI 布局

| 区域 | 组件 |
|------|------|
| 左栏 | DeviceStatusWidget（PLC / 相机） |
| 中央 | **R05 / R09 深度图视口**（并排，可拖拽分隔）+ 双工位结果表（并排） |
| 右栏 | CameraManagerWidget（参数树 + 配方导入）+ 日志 |
| 底栏 | OfflineTestWidget（离线跑 R05/R09） |

## 4. 配置

- `config/setting.json`：软件名、数据目录、PLC gateway、工位-相机映射、算法 SHM。
- `config/devices.json`：相机 id / serial / 工位归属。

## 5. 构建与运行

```bat
cmake -S . -B build -DTHIRD_PARTY_LIBRARY_DIR=G:/3rdParty -DVISION_PLC_ENABLE_LIBPLCTAG=ON -DRVC_ROOT="D:/Program Files/RVBUST/RVC/RVCSDK"
cmake --build build --config Release
```

输出：`build/apps/visual_system/Release/VisualSystem.exe`

运行后编辑同目录 `config/setting.json`，工具栏 **启动** 开启 PLC 轮询；状态栏按钮可离线跑工位周期。

## 6. 横切能力

- **日志**：EventBus → UI + `./logs/visual_system.log`
- **数据存根清理**：`DataStubRetentionCleaner` 保留最近 7 天（文件名 `yyyyMMdd_hhmmss` 精确到秒），默认每小时扫描
- **异常**：Windows MiniDump → `./dumps/`
- **单实例**：QSharedMemory + QLocalServer
- **MES**：`IMesReporter` / `NullMesReporter` 预留，未接入产线

## 7. 与 speedguide 的对应

| speedguide | VisualSystem |
|------------|--------------|
| GuideTask::_run | SequenceEngine |
| SignalManager | EventBus |
| GuideAlgo + QProcess | IAlgoService + SHM |
| AppContext | AppContext |

本工程**不依赖** speed_studio / EIP 机器人栈。
